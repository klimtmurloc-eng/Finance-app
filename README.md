# Финансы — учёт бюджета

Веб-приложение для телефона: бюджет на аванс и зарплату, категории с лимитами, траты,
регулярные платежи и статистика. Работает без интернета, все данные хранятся только на телефоне.

## Как опубликовать на GitHub Pages

1. **Создайте репозиторий.** На github.com нажмите «+» → **New repository**.
   Название, например, `finance-app`. Видимость — **Public**. Нажмите **Create repository**.

2. **Загрузите файлы.** На странице репозитория нажмите ссылку **uploading an existing file**
   (или **Add file → Upload files**). Откройте папку `D:\Claude projects\Finance app`,
   выделите **всё её содержимое** (index.html, sw.js, manifest.webmanifest, README.md и папки
   css, js, icons) и перетащите в окно браузера. Перетаскивайте содержимое, а не саму папку
   «Finance app»: файл index.html должен оказаться в корне репозитория.
   Внизу нажмите **Commit changes**.

3. **Включите GitHub Pages.** В репозитории откройте **Settings → Pages**.
   В разделе **Build and deployment**: Source — **Deploy from a branch**,
   Branch — **main**, папка — **/ (root)**. Нажмите **Save**.

4. **Дождитесь ссылки.** Через 1–2 минуты обновите страницу Settings → Pages — вверху появится
   адрес вида `https://ВАШ-ЛОГИН.github.io/finance-app/`.

5. **Установите на телефон.** Откройте ссылку на телефоне.
   - **Android (Chrome):** меню ⋮ → **Установить приложение** (или «Добавить на главный экран»).
   - **iPhone (Safari):** кнопка «Поделиться» → **На экран «Домой»**.

   После этого приложение открывается с иконки и работает без интернета.

## Как обновлять приложение

1. Загрузите изменённые файлы в репозиторий так же, как в шаге 2 (поверх старых) → **Commit changes**.
2. В файле `sw.js` должна быть увеличена версия (`VERSION`) — иначе телефон продолжит
   показывать старую версию из памяти.
3. Через пару минут откройте приложение на телефоне, закройте и откройте ещё раз — загрузится новая версия.

Ваши траты при обновлении не теряются: они хранятся в телефоне, а не в файлах приложения.

## Важно о данных

- Данные хранятся только в браузере телефона. Сохраняйте резервную копию
  (Настройки → Резервная копия) хотя бы раз в пару недель.
- Данные, внесённые при проверке на компьютере, на телефон сами не попадут.
  Чтобы перенести их: на компьютере «Сохранить копию в файл», на телефоне «Восстановить из файла».
- Код приложения в публичном репозитории виден всем, но ваших финансовых данных в нём нет.
